# Phase 3 ユーザー確定裁定

下表はユーザーが2026年11月27日の Phase 3 指示で確定した裁定です。Phase 2 の観測と推定より優先します。カード本文は対象効果を特定するための参照です。

| カード・ルール | 確定仕様 | Phase 3 の対応 |
| --- | --- | --- |
| 《夜の唱のライブ》10753310 | このスペル自身の墓場＋1は、そのスペルのネクロマンス6の支払いに含めない。墓場5では不発 | スペルの能力にだけ支払い除外を付ける。墓場4・5・6・7で、割りふり、敵リーダーの体力、両席の墓場を検査 |
| レイナ 10801120 | EP 2からプレイするとEPは2 | 0→1、1→2、2→2、および連続プレイを検査 |
| EP・SEP | それぞれ最大2 | 開始時と共通回復処理で上限を共有。手動進化は該当ポイントを消費し、効果進化は消費しないことを検査 |
| 《蒐集の発露》11042310 | 証拠なしではドローしない | カード実装を維持。証拠の有無、消費、元コストの抽出、抽出対象がない場合を検査 |
| 《世界》の提示 10503310 | 通常・エンハンスともに2枚ドロー | カードデータの枚数を修正。残り0～3枚、デッキ切れの優先、最大攻撃力の破壊を検査 |
| 《俯瞰の眼差し》11043310 | 場の左からフォロワー2体を強化 | 走査を左からに修正。対象の枚数、アミュレット混在、モード1の召喚後、盤面満杯を検査 |

《魂の捕食》が破壊した別カードのラストワードは、スペルの墓場＋1と破壊されたフォロワーの墓場＋1を使えます。この違いは公式FAQの再現ケースを実行して確認しました。 [公式FAQ](https://shadowverse-wb.com/ja/usersupport/?tab=2)

## 修正候補の扱い

- 《世界》の提示と《俯瞰の眼差し》は候補の適用前チェックを行い、隔離ソースへ適用しました。
- 《蒐集の発露》は Phase 2 の実装差異一覧から除外しました。誤りは証拠なしで引くとしたテスト期待値でした。Phase 2 の報告と候補は当時の経緯として保存し、Phase 3 の配布用パッチにはこのカードの実装差分がありません。
- 《夜の唱のライブ》とレイナは未確定一覧から除外しました。Phase 2 の観測は当時のエンジン挙動として残しています。 [Phase 2 の記録](phase2-rulings.md)

この6項目に残る未確定裁定はありません。その他の未対応能力文と分岐はカバレッジ台帳に記録しています。
