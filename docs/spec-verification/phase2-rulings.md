# Phase 2 公式裁定と観測

> Phase 2 時点の調査記録です。夜の唱のライブとレイナは [Phase 3 のユーザー確定裁定](phase3-rulings.md) で解消済みです。

## 夜の唱のライブ（10753310）

公式カードはフォロワーに計6ダメージを割りふり、ネクロマンス6で相手リーダーに2ダメージを与えます。争点は、プレイ前に墓場が5のとき、このスペル自身の墓場＋1が自分の能力の支払いに間に合うかです。 [公式カード](https://shadowverse-wb.com/ja/deck/cardslist/card/?card_id=10753310)

CygamesのFAQは墓場0で《魂の捕食》が《ドゥームズチェンジ・グレモリー》を破壊する例を扱っています。破壊したフォロワーで墓場が1増え、プレイしたスペルでさらに1増え、破壊されたフォロワーのラストワードがネクロマンス2を支払います。この裁定を隔離テストで再現しました。スペル解決中の自分のネクロマンスを扱う直接裁定は見つかっていません。 [公式FAQのネクロマンス項目](https://shadowverse-wb.com/ja/usersupport/?tab=2)

隔離エンジンで墓場5、相手リーダー20、相手フォロワー体力8からプレイすると、フォロワー体力2、墓場0、相手リーダー18になりました。これは比較用の観測です。判別に必要な実ゲーム記録では、プレイ直前に墓場5を示し、割りふり対象が生存するように体力7以上にして、プレイ後の墓場と相手リーダー体力を読む必要があります。

## タイムレスジャーニー・レイナ（10801120）

公式カードはEPを1回復します。一般ヘルプは開始時2 EPを示しています。オリヴィエの公式FAQが明記する上限2はSEPです。レイナを2 EPからプレイした場合を直接扱う公式裁定は見つかっていません。 [公式カード](https://shadowverse-wb.com/ja/deck/cardslist/card/?card_id=10801120) [公式ヘルプ](https://shadowverse-wb.com/ja/help/?tab=tab1) [公式FAQ](https://shadowverse-wb.com/ja/usersupport/?tab=2)

対戦の紹介ページにはEPとSEPをそれぞれ2回使えるという基本説明があります。回復効果で増えたEPを含めるかと、保有できるEPの上限は記載されていません。 [公式の対戦紹介](https://shadowverse-wb.com/ja/system/cardbattle/battle/)

公開試合映像の25:39、25:44、25:54付近を確認しました。この場面からは、ファンファーレ直前にEPが2だったことと、解決直後の値をセットで確定できませんでした。隔離エンジンではEP 2から3へ増えることを記録しました。公式期待値としては、独立根拠のある0→1および1→2を既存テストで検査しています。 [公開試合映像](https://www.youtube.com/watch?v=sLBBhlPIZAI&t=1533s)
