# Special entities and crest coverage

`special.cpp` checks a catalog of nine generated special-card IDs for non-deck status, runs all four supported crystallize forms through countdown and Last Words return, checks the crystallize-only Act countdown reduction, and executes the 4/4 Rush Tiger token effect. It also tests all four official Faith IDs through their source cards, including their distinct triggers, and checks the official Arcane Abyss probability ruling. Its 41 cases include direct behavioral coverage for all 37 registered crests, including trigger conditions, countdown Last Words, branch ordering, and cross-crest interactions. Parent catalog cases own the separate all-crest registry coverage.

The TSV maps each behavior case to its explicit official source card ID/page and notes relevant branch assumptions. The Arcane Abyss case uses 270 consecutive fixed seeds, tracks conservation on every action, and looks for gross distribution errors with broad binomial intervals. The official Q&A states that each faith point independently selects X, Y, or Z with equal probability, yielding probability 1/27 for (3,0,0) and 6/27 for (1,1,1). Remaining gaps are mainly additional boundary variants such as hand overflow for each generated token, full-board behavior for each crest summon, and outcomes beyond the official three-point probability example.

Sources: [official card list](https://shadowverse-wb.com/ja/cards/), [official Arcane Abyss card and Q&A](https://shadowverse-wb.com/ja/deck/cardslist/card/?card_id=90034330), [official Kargidensla source card](https://shadowverse-wb.com/ja/deck/cardslist/card/?card_id=10634120), [official Liantous source card](https://shadowverse-wb.com/ja/deck/cardslist/card/?card_id=10664120), and the repository's versioned research inputs `data/cards/svwb_crests.json`, `data/cards/svwb_special_effect_research.json`, `data/cards/svwb_special_forms.json`, plus verified rulings in `docs/仕様調査.md` §6. The two Faith records for Kargidensla and Liantous carry official-source access dates of 2026-11-24 in `data/cards/svwb_special_effect_research.json`.

No implementation defect was confirmed in the first central run. The authoring agent did not build or run the suite; parent owns serial CPU builds. Token metadata coverage is a limited nine-ID sample rather than the entire token inventory, and the official page query is not independently fetchable for every crest ID in this environment.

## Central run audit

The first central run reported four failures in this module. They were test-fixture or assertion errors, not confirmed engine defects: the crest-removal case had not seeded the faith it asserted must survive; Shrink and Expand source cards were played below their documented Combo 3 condition; the Dustdays assertion inspected the default deck's current card, which was not a follower eligible for the deck-wide buff; and Reflection's returned card was checked at the hand's last slot even though the same turn also draws a card. The fixtures/assertions now seed those conditions and locate the returned card by identity. These corrections await the parent-owned rerun.
