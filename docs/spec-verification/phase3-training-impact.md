| 修正対象 | 旧実装で差が生じる局面 | 確認できた本番デッキでの経路 |

| 《夜の唱のライブ》10753310 | 墓場5からプレイすると、旧実装はリーダーに2ダメージを与えて自分の墓場が0。確定仕様ではリーダーダメージなし、墓場6。相手フォロワーへの割りふりは共通 | ナイトメアに3枚 |
| 他のスペルのネクロマンス | 10651310を墓場3でプレイすると旧実装では回復。修正版では2枚ドローの後もネクロマンス4が不発 | 10651310の直接採用は0。フォロワーのファンファーレ、攻撃、ラストワードは支払い除外の対象外 |

| SEP上限 | 旧実装でも回復は最大2 | 直接採用されているSEP回復カードは確認できず、この修正で新たに生じる既知の遷移差はなし |
| 《世界》の提示 10503310、《俯瞰の眼差し》11043310 | ドロー枚数・デッキ切れの優先、強化対象の順序が変わる | 直接採用はともに0。確認した固定生成経路からの参照到達もなし |
| 《蒐集の発露》11042310 | 今回の裁定でエンジンの挙動は変わらない | 直接採用は0 |

実装済みネクロマンス8箇所の内訳はスペル2件（10651310、10753310）、フォロワーのファンファーレ4件（10051130、10654120、10754120、10854120）、攻撃時1件（11052120）、ラストワード1件（11054120）です。カード定義のEP回復は10801120、10653310、10873310、10854110、SEP回復は10804120です。クレスト11033312の回復も同じ共通処理を通ります。別ゲームルールの `cpp/src/engine.cpp` にあるEP初期化は、WB本番の `wb_rules.cpp` と別の実行経路です。

固定IDの生成、変身、特殊形態、クレスト、融合をデッキから追跡しました。対象を複製する汎用処理は場・手札・デッキなど既存の対象を参照するため、その処理だけでは未出現のスペルを導入できません。静的な追跡で判定できないカスタム効果や、全合法局面の組み合わせを含む到達性の証明は保留です。

| 評価対象 | 影響 |

`data/phase5c-v3-prod/nightmare__nightmare/metrics.csv` の集計列と `generation_040` の保存ファイル名に、カードID・プレイ直前の墓場・発動前後のEP/SEPを同時に記録したイベントは確認できませんでした。発生頻度と学習への寄与は未定量です。今回の静的調査から再学習の要否は判断していません。

## 探索キーの残存事項

`PositionHash` の品質と探索速度は統合後の計測候補に残します。`LegacyPosition` で盤面ID以外に省略される項目にはデッキ内容、手札補正、追加カウンタ、クレストの追加フィールドが含まれます。既知のカードID衝突の到達性調査は保持し、これらの項目が有効化される局面や影響は未確認です。探索方式の実装差分はありません。 [Phase 2 の監査](phase2-search-audit.md)
