### 第1部：確定仕様まとめ

#### 1. 基本パラメータ・試合開始・PP・エクストラPP

##### 1.1 基本定数と試合開始処理

* **基本定数**:


* デッキ枚数: 40枚。


* 同名カード投入上限: 原則3枚（フォーマット別の禁止・制限に従う）。


* リーダー初期体力 / 最大体力: 通常20（特殊イベントでの初期値変更や、カード能力による最大体力変更効果あり）。


* 手札上限: 9枚。


* 盤面（場）の上限: 各プレイヤー最大5枠（フォロワーとアミュレットの合計。超進化フォロワーも1体カウント）。


* リーダーエリア上限: 最大5個（クレストと信仰の合計）。


* PP最大値: 通常10（カード能力による上限変更効果あり）。


* 初期EP / 初期SEP: 先攻・後攻ともに各2個。




* **試合開始・マリガン・1ターン目ドロー**:


* 先攻・後攻はバトル開始時にランダムで決定される。


* 初期手札は先攻・後攻ともに4枚で、最初に引いた4枚から任意の枚数（0〜4枚）を選んで1回だけ引き直し（マリガン）が可能。


* マリガンで戻したカードそのもの（現物）が同じ引き直しで再び配られることはない（デッキ内の別個体である同名カードを引く可能性はある）。


* 旧作と異なり、後攻1ターン目の2枚ドローは廃止され、**先攻・後攻ともに1ターン目を含む各ターン開始時に1枚ドロー**する。




* **通常PPの増加・回復**:


* ターン開始時に最大PPが+1（通常上限10）され、現在PPが最大値まで全回復する（1ターン目は最大PP 1から開始）。





##### 1.2 エクストラPP（後攻専用）

* **所持・効果**: 後攻プレイヤーのみが所持し、自ターン中にボタンを押すことでそのターン中のみ使用可能PPを+1する。


* **使用回数と回復条件**: 初期使用可能回数は1回（1〜5ターン目までに使用可能）であり、1〜5ターン目に使用済みの場合に限り**後攻6ターン目開始時に使用権が1度回復**する（1試合最大2回）。1〜5ターン目に未使用のまま6ターン目を迎えた場合は回復せず（蓄積はされない）、その試合中1回しか使えない。


* **制約事項**: 同じターンでの連続使用は不可で、使用後にカードをプレイすると取り消し不可となる。余剰分はターン終了時に消滅し次ターンへ持ち越せない。


* **最大PP・覚醒との関係**: 最大PPが10の状態でも使用可能だが、エクストラPPで一時的にPPを7にしてもドラゴンクラスの「覚醒」（最大PP7以上）は発動しない。

#### 2. ターン進行・行動上限・勝敗判定

##### 2.1 ターン開始時の処理順序

公式ルールで明記されている要素と、第三者（Go To Beyond）の実機検証で確認されている相対順序は以下の通りです（PP増加・回復や攻撃権リセットとの厳密な挿入前後関係は第2部 U02参照）。

1. **アミュレットのカウントダウン進行**: カウントダウンが1進み、0に達したアミュレットはこの段階で破壊される（ただし、この破壊に伴うラストワードの発火は手順3のタイミングに回される）。


2. **「自分のターン開始時」のクレスト効果**: 付与された古い順に発動する。


3. **「自分のターン開始時」の場のカード効果および手順1のラストワード**: 場に出たのが古いカード（UI上の自陣左）から順に発動する。


4. **通常ドロー**: デッキからカードを1枚引く（手順2・3で手札が9枚に達していた場合、このドローは上限超過により破棄される）。



* ※デッキからの「直接召喚」が絡む事例では、カウントダウン進行後に直接召喚で場に出た状態でアミュレットのラストワードが解決され、最後に直接召喚フォロワーの誘発効果が処理された挙動が観測されている。



##### 2.2 メインフェーズと同名カード行動回数上限

* メインフェーズでは、手札からのカードプレイ、フォロワーの攻撃、EP/SEPによる進化・超進化、アミュレットのアクト、手札の融合、エクストラPPの使用を任意の順序で行う。


* **同名カードの1ターン行動回数上限**（公式ヘルプ規定・個体をまたぐ同名判定でカウント）:


* 同名カードのプレイ: 1ターン最大20回。


* 同名カードによる攻撃: 1ターン最大20回。


* 同名カードのアクト: 1ターン最大20回。





##### 2.3 ターン終了時の処理順序

実機検証（Go To Beyond / GameWith Q&A）に基づく代表的な終了時効果の処理順は以下の通りです。

1. 「自分のターン終了時」のクレスト効果（付与された古い順）。


2. 「自分のターン終了時」の場のカード効果（場に出た古いカード＝自陣左から順）。


3. 相手の場にある「相手のターン終了時」のカード効果（《操り人形》の破壊など）。



* ※ターン終了時処理の途中で場のフォロワーが破壊された場合でも、非割り込みルールによりそのラストワードは即座には割り込まず、既に予約されている一連のターン終了時効果の後に処理待ち列へ追加される。



##### 2.4 勝敗・デッキ切れ・ターン上限裁定

* **勝敗判定の即時割り込み**: カードテキストの記述順（上から下）に1ステップずつ解決し、いずれかのリーダー体力が0以下になった瞬間またはデッキ切れ敗北条件を満たした瞬間に即座に勝敗が決定し、キュー内の残り処理はすべて強制キャンセルされる。


* 例：「相手リーダーに3ダメージ。自分リーダーに2ダメージ」の順で記述された効果では、相手体力を先に0以下にした時点で自傷処理の前に勝利が確定する。




* **デッキ切れ（ライブラリーアウト）**: 最後の1枚を引いた瞬間ではなく、**山札が0枚の状態でカードを引く処理（ドロー要求）が発生した瞬間**に敗北する（残り1枚で「2枚引く」場合は2枚目のドロー時に敗北）。


* 例外として、死神が「勝利のカード」に変身済みの場合（《マゼルベイン》等）は、デッキ0枚からドローした瞬間に特殊勝利となる。




* **ターン数上限**: 後攻40ターン終了時に未決着の場合、引き分けではなく「両者敗北」となる。


* **同時リーサル（双方HP0以下）**: 《残虐の炸裂》（「お互いのリーダーが3ダメージを受けます」）をプレイして同時に双方の体力が0になった場合、引き分けではなく**相手プレイヤーが勝利**する公式Q&A裁定が存在する（他の誘発経路での一般則は第2部 U04参照）。

##### 3.2 超進化固有の能力（公式確定）

超進化したフォロワーは「進化済み」として扱われ、以下の3つの固有能力を獲得します。

1. **自分のターン中のダメージ無効**: 自分のターン中に受けるダメージがすべて0になる（超進化したターンだけでなく、以後の自分のターン中も有効。相手ターン中は無効）。


2. **自分のターン中の能力破壊耐性**: 自分のターン中は能力によって破壊されない（相手フォロワーの【必殺】や自軍の破壊効果にも耐える。相手ターン中は無効であり、消滅・変身は防げない）。


3. **攻撃中の相手フォロワー破壊時1ダメージ**: 超進化フォロワーが**相手フォロワーを攻撃しており、その攻撃中に相手フォロワーを破壊したとき**（戦闘ダメージによる破壊だけでなく、攻撃中の能力ダメージ等による破壊も含む）、相手リーダーに1ダメージを与える。



##### 3.3 手動進化・コスト免除進化・能力による自動進化の区別

* **能力による自動進化／自動超進化**:
* EP/SEPを消費しないため、**1ターン1回の手動進化制限とは別枠**として扱われる。


* キーワード能力の【進化時】および【超進化時】は**働かない**（《勇壮の堕天使・オリヴィエ》公式Q&A）。


* 一方、キーワードではない「これが進化したとき、〜」というテキスト能力は自動進化・自動超進化でも**働く**。




* **「EPを消費せずに進化できる」コスト免除効果**:
* 能力による直接進化とは異なり、手動進化のコスト免除扱いとなるため、進化解禁ターンなどの通常条件が関係する。

#### 4. 戦闘・キーワード能力・アミュレットのアクト

##### 4.1 基本戦闘ルール

* フォロワーは場に出たターンには攻撃できず（召喚酔い）、次の自分のターンから1ターンに1回、相手リーダーまたは相手フォロワーへ攻撃可能となる（多段攻撃アイコン持ちは複数回攻撃可）。


* アミュレットは通常攻撃できず、攻撃対象にもならない。


* フォロワー同士の交戦では、攻撃時・交戦時能力の処理後に双方の攻撃力分のダメージを同時に与え合い、体力が0以下になったフォロワーは破壊される。


* 攻撃力0のフォロワーや、ダメージ軽減によって0ダメージになった場合でも、【必殺】の破壊効果は成立する。



##### 4.2 キーワード能力の確定定義

| キーワード | 確定定義・例外条件（公式バトルTips・用語集準拠） |
| --- | --- |
| **守護 (Ward)** | 相手フォロワーは【守護】を持たない他フォロワーやリーダーを攻撃できない。ただし【潜伏】または【威圧】を併せ持つ場合、そちらが優先されて【守護】は無効になる。

 |
| **疾走 (Storm)** | 場に出たターンから相手フォロワーおよび相手リーダーを攻撃できる。

 |
| **突進 (Rush)** | 場に出たターンから相手フォロワーを攻撃できる（相手リーダーは攻撃不可）。

 |
| **必殺 (Bane)** | 交戦した（攻撃した／攻撃された）相手フォロワーをダメージ交換後に体力に関わらず破壊する。与えるダメージが0（攻撃力0や【バリア】軽減時）でも破壊が成立する（自ターン中の超進化フォロワーは破壊耐性により破壊不可）。

 |
| **ドレイン (Drain)** | 攻撃によって実際に与えたダメージと同量だけ自分のリーダーを回復する。

 |
| **バリア (Barrier)** | フォロワーまたはリーダーが次に受けるダメージを1度だけ0にし、その後失われる（【必殺】との交戦による破壊は防げない）。

 |
| **威圧 (Intimidate)** | 相手フォロワーから攻撃されない（能力による対象選択やダメージは受ける）。

 |
| **潜伏 (Ambush)** | 相手能力によって選択されず、相手フォロワーからも攻撃されない。自身が攻撃するか、潜伏フォロワー自身が能力でダメージを与えると解除される。

 |
| **オーラ (Aura)** | 相手の能力によって選択されない（ランダム対象・全体効果・戦闘そのものは防がない）。

 |
| **攻撃不可** | カードテキストに指定された攻撃行動を禁止する。

 |

##### 4.3 アミュレットの「アクト (Engage)」

* アクト能力を持つアミュレットに対し、自分のターン中に任意タイミングで発動操作を行える（同一カードにつき1ターン1回）。


* コスト指定がない場合は0PP、指定がある場合はそのPPを支払えるときに発動できる。


* 場に出たターンでも原則使用可能（《光の香炉》等で確認）であり、対象不在や手札0枚などで一部処理が実行できない場合でも発動自体は可能（実行可能な部分のみ処理し、不能部分はスキップ）。

#### 5. 効果解決エンジン・上限処理・状態遷移

##### 5.1 効果解決の大原則と非割り込みキュー

* **非割り込み原則**: 一連の能力の処理中に新たに能力が誘発しても、現在の処理には割り込まず、待機列（キュー）の末尾（または規定のカテゴリ順）へ追加されて順次処理される。


* **単一カード内の処理順**: 1枚のカードに複数の効果が書かれている場合、原則としてテキストの上側（左側）から1文ずつ順に実行される。


* **ファンファーレと「場に出たとき」の分離**:
* **ファンファーレ**: 手札からコストを支払う等して「プレイ」して場に出たときのみ発動する（能力による場出し・トークン生成・直接召喚では不発）。


* **場に出たとき**: プレイ以外の方法を含め、実際に場に出たときに発動する。


* 同一カードが【超進化時】と誘発【ファンファーレ】を持つ場合、公式Q&A（《畏怖の象徴・オメガオテプ》）により【超進化時】の後に【ファンファーレ】が順次働く。





##### 5.2 同時誘発時の解決優先度（実機検証ベースの暫定統合順）

公式に確認された部分（「ファンファーレはクレストより先」「交戦時はターンプレイヤー側が先」「破壊時のネクロマンスは自身の破壊による墓場+1の後」）と、第三者検証（攻略Wiki / GameWith）によるキュー優先度整理は以下の通りです（全イベントへの完全適用は第2部 U10参照）。

* **同カテゴリ内の基本原則**: ①ターンプレイヤー優先 → ②同一プレイヤー内では古いカード（場に出た順／付与された順＝UI上の自陣左・相手陣右）優先。


* **カテゴリ優先度（調査1 Wiki整理）**:


1. ファンファーレ / 【進化時】 / 【超進化時】 / アクト等（クレストより先であることは公式Q&A確定）


2. 「場に出たとき」「場を離れたとき」等の誘発能力


3. 破壊されたとき（ラストワード等。調査2整理では「ターンPラストワード → 非ターンPラストワード → 新規誘発別効果 → その中で発生したラストワード」の順）


4. ターンプレイヤーのリーダーエリア（クレスト等：付与された古い順）


5. ターンプレイヤーの場（古い順＝自陣左から順）


6. 非ターンプレイヤーのリーダーエリア（クレスト等：付与された古い順）


7. 非ターンプレイヤーの場（古い順＝相手陣右から順）


8. 直接召喚などデッキ内で働く能力





##### 5.3 領域上限超過時の処理

* **盤面（5枠）満杯時の処理（公式用語集規定）**:


* 手札・デッキからの場への移動や直接召喚は実行されない（移動しない）。


* トークン等の生成による場出しは、上限超過分が場に出ずに消滅（失敗）する。


* このとき、場に出なかったカードは「破壊」でも「消滅」でもなく**墓場は増えない（+0）**。また、実際に場に入っていないため「場に出たとき」やラストワードも一切発生しない。




* **手札（9枚）満杯時の処理（公式用語集規定）**:


* 複数枚を加える場合、カードテキストの前側から順に手札へ加わり、上限9枚を超過したカードのみが溢れて破棄される。


* **デッキからのドロー溢れ・手札へのトークン生成溢れ・場からのバウンス溢れ**は、いずれも手札に入らず破棄され、**墓場が+1される**。


* 手札溢れによる墓場増加は「破壊」ではないため、ラストワードは発動せず、「破壊されたフォロワー履歴」にも登録されない。

#### 6. 墓場・固有領域・クラス固有メカニズム

##### 6.1 墓場（Cemetery）の増減ルール

墓場はカード実体ではなく数値カウンターとして管理されます（**リアニメイト用の「破壊されたフォロワー履歴」とは必ず別データで管理すること**）。

* **墓場が増える事象**: スペルプレイ完了（+1）、自分のフォロワー/アミュレット破壊（+1）、手札上限超過によるドロー/生成/バウンス溢れ（+1）、手札を捨てる処理（捨てた枚数分）。


* **墓場が増えない事象（0）**: 消滅、変身、通常バウンス、融合素材としての消費、盤面満杯による生成失敗、土の印の統合による消滅。



##### 6.2 リーダーエリア（クレスト・信仰）

* リーダーエリアにはクレストと信仰を合わせて**最大5個**まで保持できる。


* **クレスト**と**信仰**は別のカード分類であり、公式Q&Aにより「クレスト数を参照する効果」に信仰は含まれない。


* **重複禁止**: 同名のクレストおよび同名の信仰は重複して保持できない（同名クレスト再取得時は不発となり、既存カウントダウンもリセットされない）。


* **信仰**: 信仰カードをデッキに入れている場合、バトル開始時に初期リーダーエリアへ配置される。



##### 6.3 クラス固有・汎用メカニズムの確定仕様

* **コンボ (Combo)**: そのターン中に自分がプレイしたカード枚数（コンボ能力を持つカード自身もカウントに含まれる）。


* **スペルブースト (Spellboost)**: スペルをプレイするごとに手札の該当カードのブースト値が+1される。手札でスペルブーストされたカードが**デッキに戻った場合もブースト状態を保持する**（SVWB新規仕様）。


* **覚醒 (Overflow)**: 自分の**最大PPが7以上**の状態（エクストラPPによる一時的な7PPでは非該当）。


* **土の印 / 土の秘術 (Earth Sigil / Earth Rite)**（公式用語集規定）:


1. 土の印を持つアミュレットが場に出ると土の印1を持ち、既に場に別の土の印があれば**それらを消滅させて（墓場+0）土の印の数を1つに合算**する。


2. 土の印を持つカードは能力で破壊できず、相手の能力で選択されない。


3. 土の秘術NでN消費し、土の印の数が0になると破壊される（墓場+1）。


4. 「土の印を+Nする」効果では既存の土の印に加算し、場に存在しない場合は《大地の魔片》を場に出して指定値にする。




* **ネクロマンス (Necromancy)**: 墓場がN以上ならN消費して発動。破壊時効果では自身の破壊による墓場+1の後に消費判定を行う。


* **リアニメイト N (Reanimate)**（公式用語集規定）:


* バトル中に破壊された自分のフォロワー履歴から、コストN以下の候補を抽出し、その中の**最大コストの候補のみ**を対象とする（消滅や手札溢れは対象外）。


* 最大コストの候補が複数ある場合、**破壊された回数に応じた重み付きランダム**で1体を選び、その同名フォロワーに「死者」タイプを付与して場に出す。




* **エンハンス / アクセラレート / 結晶（公式用語集規定）**:


* 残りPPがエンハンス値以上の場合、通常コストの代わりにエンハンス値を支払ってプレイする（元コストが増加してエンハンス値を超えていてもエンハンス値が優先される事例あり）。


* **複数のエンハンスを持つカード**は、残りPP以下で最大のエンハンス値を支払い、**それ以下の値のエンハンス能力もすべて発動する**（例：PP8でエンハンス5と8を持つ場合、8PP消費で5と8の両方が発動）。


* アクセラレート・結晶は通常コストが支払えない場合にスペル／アミュレットとしてプレイし、複数候補がある場合は残りPP以下で最大のコスト候補が適用される。




* **融合 (Fusion)**: 1ターンに1回（カードごと）、手札から指定素材を取り除いて（墓場+0）強化・変身する。融合変身後のカードは手札内で**融合元カードがあった位置**に配置される。


* **モード (Mode)**: 指定数の能力を選択する。**条件を満たさないモードも選択可能だが、その能力は働かない**。


* **連携 N (Rally)**: このバトル中に自分の場に出たフォロワーの累計枚数を参照する。


* **奥義 / 解放奥義**: ゲージは「現在のターン数 ＋ そのカードが手札にある間に自分のフォロワーが進化した回数」で算出され、10以上で奥義、15以上で解放奥義が働く。


* **直接召喚 (Invocation)**: 場に空きがある場合のみデッキから場に出る。同一タイミングで複数種の直接召喚条件を満たした場合、場に出る順序はランダム。同名カードがデッキに複数枚あっても、1度のタイミングでは1枚のみ召喚される。

#### 7. 対象選択・スタッツ計算・割り振り処理

* **対象選択と不在時のプレイ可否（公式規定）**:


* **対象選択を必要とするスペル**: 指定された数の対象をすべて選べなければ**プレイ不可**。


* **対象選択を必要とするファンファーレ（フォロワー／アミュレット）**: 対象不在や不足でも**プレイ可能**であり、選べるだけ選んで解決する。




* **スタッツ・ダメージ計算規則（公式用語集規定）**:


* `+A/+B` は攻撃力をA増やし、現在体力と最大体力をB増やす。`-A/-B` は攻撃力をA減らし、現在体力と最大体力をB減らす。


* ダメージ量は0未満にならず、ダメージの増減効果とダメージを一定値にする効果が重なった場合は**増減が先に適用**される。




* **ランダムおよび「ダメージを割りふる」処理（公式規定・実機確認）**:


* **「ダメージを割りふる」効果**: 真のランダムではなく、**場に出たのが古いフォロワー（UI上の自陣左・相手陣右）から順番**に、各フォロワーの現在体力分までダメージを割り振る。余剰ダメージは、対象にリーダーが含まれる場合はリーダーへ、含まれない場合は最後のフォロワーへ割り振られる。


* 複数カードを場に出す効果（例：《ララミア》）での出現順は、選択順ではなく**手札の左から順**となる。

### 第3部：C++対戦シミュレーター実装に向けた設計指針

両調査の知見を統合し、手戻りを最小化するC++アーキテクチャ上の推奨設計は以下の通りです。

1. **データの分離管理（混同防止）**


* **墓場と破壊履歴の分離**: `cemetery_count`（整数カウンター）と `destroyed_follower_history`（印刷コスト・実効コスト・カードIDを保持するリスト）を完全に分離し、手札溢れやスペルプレイがリアニメイト対象に混入しないようにします。


* **進化状態の細分化**: 進化イベントには `point_spent`（EP/SEP消費有無）、`evolution_kind`（通常進化／超進化）、`evolution_source`（手動／コスト免除手動／能力自動）を持たせ、1ターン1回制限の消費と【進化時】/【超進化時】の誘発判定を分離します。


* **個体の行動状態と同名制限の分離**: 個別のフォロワー/アミュレットの `attacked_this_turn` / `engaged_this_turn`（変身・コピーでリセット）と、プレイヤー単位の `card_name_action_counts`（プレイ・攻撃・アクトの1ターン20回制限）を別々に管理します。


* **場に出た順序IDの保持**: 画面上の左右ではなく、場に出た順の単調増加ID（`creation_order`）を割り振り（変身しても維持）、同時誘発の解決順およびダメージ割り振り順に利用します。




2. **検証フラグと決定論的リプレイログの導入**


* 各ルールに `OfficialConfirmed` / `ObservedUnverified` / `Unresolved` のメタデータを紐づけ、第2部の未確定項目（U01〜U14）は設定オブジェクト経由で切り替えられるようにします。


* ランダム処理（マリガン、リアニメイト、直接召喚、ランダム対象）は、乱数シード・抽選タイミング・その瞬間の候補集合・抽選結果を構造化ログへ出力し、実機との対照テスト（回帰テスト）が可能な設計とします。
