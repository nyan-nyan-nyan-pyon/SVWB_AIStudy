# SVWB 確定ミラー解析

収束条件を満たした第25世代のモデルを評価した。確定40枚デッキを両側で使用し、探索ノイズと温度サンプリングを無効にした。

| 指標 | 結果 |
| --- | ---: |
| ミラー試合数 | 2,000 |
| 先攻勝率 | 48.90%（978勝） |
| 後攻勝率 | 51.10%（1,022勝） |
| 引き分け・両者敗北率 | 0.00%（両者敗北0件） |
| 平均手番数 | 14.62 |
| 平均決着ラウンド | 7.56 |
| 対ランダム勝率 | 100.00%（200/200） |
| 最終 ΔV | 0.02651 |
| 最終 Δπ | 0.02415 |
| 学習用自己対戦 | 12,500試合 |
| 世代処理時間の合計 | 858.42秒 |

対前世代の5世代平均は 第11〜15世代 49.70%、第16〜20世代 51.10%、第21〜25世代 50.20%。

競技者Aをミラーの先攻・後攻に1,000試合ずつ割り当てた。初手CSVはA視点で先攻・後攻・合算を集計した。保持は交換前の4枚から残した現物、初手存在は交換後かつ第1ドロー前の4枚にあることを指す。差は観測された勝率の差で、単位はパーセントポイント。比較群が空なら空欄とした。

手順ログには選んだマリガン、実行した各ターンの行動、MCTSの上位候補を収録した。評価シードはミラーが `722026`、対ランダムが `722027`。
